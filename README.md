# E-Commerce Sales & Performance Dashboard 📊

## 🚀 Project Overview
An end-to-end data analysis and visualization project built to track, analyze, and present key business metrics for an e-commerce platform (using the Olist dataset). The dashboard provides clear insights into total revenue, customer base, top-performing cities, and revenue trends over time.

## 🛠️ Tools & Technologies Used
- **Power Query:** Data extraction, transformation, and cleaning (ETL).
- **SQL:** Querying and data extraction from relational databases.
- **Power BI Desktop:** Data modeling, DAX measures, and interactive data visualization.

## 📌 Key Performance Indicators (KPIs)
- **Total Revenue:** $2.19 Billion
- **Total Orders:** 99.44K
- **Total Customers:** 96.09K

## 🔍 Key Insights & Features
- **Geographical Analysis:** Identified top cities generating the highest revenue (e.g., Rio de Janeiro, São Paulo) to target future marketing campaigns.
- **Trend Analysis:** Tracked revenue fluctuations across quarters to spot peak performance seasons.
- **Interactive Filtering:** Integrated order status slicers to filter data dynamically (Approved, Shipped, Canceled, etc.).

## 📂 Dataset Source
The raw data used for this project is publicly available on [Kaggle - Olist E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).
